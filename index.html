Autoclicker de Live do TikTok

Script que clica sozinho num ponto fixo da tela — feito pra não precisar ficar tocando "amei" sem parar durante uma live e cansar o dedo. Mesmo script funciona em Windows e Linux.

Baixar

Pegue os arquivos do repositório antes de seguir o passo a passo:

tiktok_live_autoclicker.py requirements.txt Ver repositório

🪟 Instalar no Windows

  1. Instale o Python 3.9+. No instalador, marque a caixa "Add python.exe to PATH" antes de clicar em Install.
  2. Coloque tiktok_live_autoclicker.py e requirements.txt na mesma pasta.
  3. Abra o PowerShell (ou CMD) nessa pasta e instale as dependências: 
    pip install -r requirements.txt
  4. Rode o script: 
    python tiktok_live_autoclicker.py

🐧 Instalar no Linux

  1. Garanta que tem Python 3 e pip instalados: 
    sudo apt install python3 python3-pip python3-venv   # Debian/Ubuntu
sudo dnf install python3 python3-pip                # Fedora
  2. Crie um ambiente virtual (recomendado) e instale as dependências: 
    python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
  3. Rode o script: 
    python tiktok_live_autoclicker.py
Atenção — X11 vs Wayland: o script só funciona em sessões X11. Se sua distro usa Wayland por padrão (Ubuntu/Fedora recentes), rode echo $XDG_SESSION_TYPE pra checar; se aparecer wayland, troque para "Xorg"/"on Xorg" na tela de login antes de rodar o script.

Como usar

  1. Abra a live do TikTok e deixe a janela visível, sem minimizar.
  2. Posicione o mouse exatamente em cima do botão de coração/"amei".
  3. Use os atalhos abaixo para controlar o script.
F8 marca a posição do botão
F6 liga / pausa os cliques
ESC encerra o programa
Use com moderação: é uma ferramenta pra facilitar o uso pessoal (evitar dor no dedo), não pra deixar rodando o dia inteiro. Cliques automatizados em excesso podem ser entendidos pela plataforma como manipulação de engajamento e a conta pode sofrer restrições.
